## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Studio server → Backlot API | Studio fetches scenario data over HTTP with the session-held Basic Auth header (Phase 1 handler) |
| Backlot API data → rendered HTML | API-sourced scenario strings (names, roles, tags, endpoints) are interpolated into the Razor view |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Information Disclosure | `IndexModel.OnGetAsync` exception path | mitigate | Catch only `HttpRequestException`/`TaskCanceledException` and show a generic message; never render exception details or the API base URL secret into the page |
| T-02-02 | Tampering / XSS | Scenario fields rendered in `Index.cshtml`, including the `onclick="openScalarPanel('...')"` attribute | mitigate | Rely on Razor automatic HTML-attribute encoding for all API-sourced values; do not use `@Html.Raw`; endpoint value is API-sourced (no user control) |
| T-02-03 | Elevation of Privilege | Unauthenticated access to `/scenarios` | mitigate | `[Authorize]` on `IndexModel`; cookie auth from Phase 1 redirects anonymous users to login; `UnauthorizedAccessException` propagates to the 401 handler (not swallowed) |
| T-02-SC | Tampering | npm/NuGet installs | accept | No package installs in this plan — all dependencies are in-box .NET 10 and Phase 1 artifacts; no supply-chain surface introduced here |
</threat_model>
