<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → Scalar CDN | The Scalar Vue bundle is fetched from a third-party CDN and executes in the user's browser |
| Browser → /openapidoc.json | The OpenAPI spec is served as a public static file and rendered by Scalar |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-04 | Tampering / Supply Chain | Scalar CDN script in _Layout.cshtml | mitigate | Pin to exact version 1.60.0 (never a floating tag) and apply the canonical SRI integrity sha384 hash plus crossorigin anonymous so a tampered bundle is rejected by the browser |
| T-02-05 | Information Disclosure | openapidoc.json served publicly from wwwroot | accept | The spec documents the public Backlot API surface and contains no secrets; serving it from wwwroot (not the content root) avoids exposing appsettings or other root files |
| T-02-06 | Denial of Service / Resource leak | Double-mounting Scalar on every Turbo navigation | mitigate | Single-init sentinel (panel.dataset.scalarInitialized) on a data-turbo-permanent element prevents repeated Vue mounts and listener leaks |
| T-02-SC | Tampering | npm/NuGet installs | mitigate | No package installs — all assets are pinned CDN tags with SRI; legitimacy audit in RESEARCH.md confirms no SLOP/SUS packages and no install step |
</threat_model>
