    Namespace: Backlot.Studio.Pages.Roles. Class: DetailModel : AuthenticatedPageModel. Attribute: [Authorize].

    Route parameter: [BindProperty(SupportsGet = true)] public string Uid { get; set; } = string.Empty; (or via @page directive in the .cshtml with route template "/roles/{uid}").

    Properties:
    - System.Text.Json.JsonElement? RoleData — holds the deserialized body from GetRoleDetailAsync; nullable because the call may fail
    - string? ErrorMessage
    - bool CanWrite — derived from __Permission after RoleData is loaded; default false

    OnGetAsync(): call SetUserContext(). Validate Uid is non-empty (if empty, redirect to /roles). Use SafeApiCall to call _api.GetRoleDetailAsync(Uid). On success: assign RoleData. Extract CanWrite: if RoleData.HasValue, try to get "__Permission" property from the JsonElement, then try to get "CanWrite" bool — use TryGetProperty + GetBoolean pattern; if missing or fails, default to false. Catch (HttpRequestException or TaskCanceledException) → set ErrorMessage = "Could not load role details. The role may not exist or the API may be unavailable."

    Add helper methods for use in the view (private static or internal):
    - GetStringField(JsonElement data, string key): tries TryGetProperty(key), returns GetString() or ToString() for the value, returns null if key not found
    - GetSkills(JsonElement data): tries TryGetProperty("__Skills"), if found and is an array, returns IEnumerable&lt;string&gt; by iterating each element's GetString(). Returns empty enumerable if missing.
    - GetPermissions(JsonElement data): tries TryGetProperty("__Permission"), if found tries to get CanCreate, CanRead, CanWrite as bools. Returns a named tuple (bool CanCreate, bool CanRead, bool CanWrite) defaulting all to false.
    - GetNonSystemFields(JsonElement data): iterates all properties of the JsonElement object, skips properties whose name starts with "__", returns IEnumerable&lt;(string Key, string Value)&gt; where Value is the string representation of the JsonElement value.
    - GetPageTitle(JsonElement data): calls GetSkills to get the primary type; returns first skill or "Role".

    Make these helpers accessible to the view by either making them public instance methods or exposing computed properties:
    - public string PageTitle => RoleData.HasValue ? GetPageTitle(RoleData.Value) : "Role"
    - public (bool CanCreate, bool CanRead, bool CanWrite) Permissions => RoleData.HasValue ? GetPermissions(RoleData.Value) : (false, false, false)
    - public IEnumerable&lt;string&gt; Skills => RoleData.HasValue ? GetSkills(RoleData.Value) : []
    - public string? LastModifiedDate => RoleData.HasValue ? GetStringField(RoleData.Value, "__LastModifiedDate") : null
    - public IEnumerable&lt;(string Key, string Value)&gt; Fields => RoleData.HasValue ? GetNonSystemFields(RoleData.Value) : []

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser→Studio route param | {uid} route segment is untrusted; passed to GetRoleDetailAsync and GetRoleRelationsAsync as a raw string |
| Studio→Backlot API | uid values posted in JSON body { For: uid } or { Uid: uid }; API validates the uid |
| Turbo Frame response | Relations partial returns only the frame element with Layout=null; no full-page HTML is leaked into the frame swap |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-05 | Tampering | {uid} route parameter passed to API | mitigate | Server-side only: uid is forwarded directly to the Backlot API POST body; API enforces uid format/existence; no server-side uid parsing or SQL usage |
| T-03-06 | Information Disclosure | Full field set from seekbase/detail rendered in HTML | accept | Studio is an authenticated management tool; all users reaching this page have valid credentials; __Permission badges surface access levels explicitly |
| T-03-07 | Spoofing | Relations partial Layout=null exposes Turbo Frame response without auth headers | mitigate | Page carries [Authorize] attribute; cookie auth gates the route; SafeApiCall handles 401 redirect; the frame response still goes through ASP.NET Core auth pipeline |
| T-03-08 | Elevation of Privilege | Edit button link rendered even when CanWrite=false (disabled state) | accept | Disabled button is a UX hint only; actual edit form in Phase 4 enforces CanWrite server-side; disabling the button prevents accidental navigation, not malicious access |
| T-03-SC | Tampering | npm/pip/cargo installs | accept | No new packages installed in this plan |
</threat_model>
