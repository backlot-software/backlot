    - Constructor: injects `IBacklotApiClient apiClient` (stored as `_apiClient`)
    - Properties: `[BindProperty] public LoginInputModel Input { get; set; } = new();` and `[FromQuery] public string? ReturnUrl { get; set; }`
    - Nested class `LoginInputModel`: `[Required] public string Username { get; set; } = string.Empty;` and `[Required] [DataType(DataType.Password)] public string Password { get; set; } = string.Empty;`
    - `OnGetAsync()`: returns `Page()` — if already authenticated, let the framework handle the redirect
    - `OnPostAsync()` — CRITICAL ORDER (per RESEARCH.md Pitfall 5 — validate credentials before signing in):
      1. Check `ModelState.IsValid`; if not, return `Page()`
      2. Base64-encode `"username:password"` as UTF-8 bytes: `Convert.ToBase64String(System.Text.Encoding.UTF8.GetBytes($"{Input.Username}:{Input.Password}"))`
      3. Store in session FIRST: `HttpContext.Session.SetString("BasicAuthHeader", encoded)`
      4. Call `await _apiClient.IsAuthenticatedAsync()` — this uses BasicAuthHandler which reads the session key just set
      5. If NOT authenticated: remove session key (`HttpContext.Session.Remove("BasicAuthHeader")`), add model error with key `string.Empty` and message "Invalid username or password." (exact copy per UI-SPEC §Copywriting), return `Page()`
      6. If authenticated: build `ClaimsPrincipal` with a single `ClaimTypes.Name` claim set to `Input.Username`
      7. Call `await HttpContext.SignInAsync(CookieAuthenticationDefaults.AuthenticationScheme, principal)` with `AuthenticationProperties { IsPersistent = false }`
      8. Return `LocalRedirect(ReturnUrl ?? "/")`
    - Required usings: `System.Security.Claims`, `Microsoft.AspNetCore.Authentication`, `Microsoft.AspNetCore.Authentication.Cookies`, `Microsoft.AspNetCore.Mvc`, `Microsoft.AspNetCore.Mvc.RazorPages`, `Backlot.Studio.Services`, `System.ComponentModel.DataAnnotations`

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → Login POST | Username/password submitted via form POST; must not be visible to JS, must be HTTPS |
| Login POST → ISession | Credentials stored in server-side session after API validates; never echoed to browser |
| ISession → Backlot API | BasicAuthHandler reads session and injects Authorization header — HTTPS only |
| Backlot API 401 mid-session → Browser | Must redirect at top level (full page), not inside a Turbo Frame |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | Login form CSRF | mitigate | `@Html.AntiForgeryToken()` on login form + `asp-page` tag helper on form triggers built-in Razor Pages antiforgery validation; `data-turbo="false"` ensures standard browser round-trip |
| T-03-02 | Tampering | Logout CSRF | mitigate | Logout is `OnPostAsync` only (not a GET link); logout form in `_Sidebar.cshtml` includes `@Html.AntiForgeryToken()`; clicking a GET link cannot trigger logout |
| T-03-03 | Information Disclosure | Username/password in browser | mitigate | Credentials never stored client-side; form is POST (not GET, no URL logging); `data-turbo="false"` prevents Turbo Drive from caching the request; `autocomplete="current-password"` lets browser autofill without echoing value |
| T-03-04 | Information Disclosure | Credentials in auth cookie | mitigate | Auth cookie contains only `ClaimTypes.Name` (username string) — NOT the password. Password is stored only in `ISession["BasicAuthHeader"]` as an opaque server-side value |
| T-03-05 | Elevation of Privilege | Sign-in before credential validation | mitigate | `OnPostAsync` calls `IsAuthenticatedAsync()` BEFORE `SignInAsync`; on failure the session key is removed and the cookie is never issued |
| T-03-06 | Elevation of Privilege | 401 inside Turbo Frame | mitigate | `AuthenticatedPageModel.SafeApiCall` emits `Turbo-Visit-Control: reload` header; Turbo 8 performs a full-page visit to /login instead of a frame-scoped render |
| T-03-07 | Information Disclosure | whoami response shape | accept | `WhoAmIAsync` returns `object?`; `.ToString()` on a `JsonElement` may include JSON literals; a JsonElement string-check extracts the actual value safely; no credential exposure risk |
| T-03-SC | Tampering | NuGet supply chain | accept | No external NuGet packages installed in this plan; all auth APIs are in-box ASP.NET Core shared framework |
</threat_model>
