<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → ASP.NET Core | CDN script/link tags load third-party JS/CSS; a compromised CDN could inject malicious code |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Tampering | CDN assets (Bootstrap, Turbo, Bootstrap Icons) | mitigate | Pin exact versions in CDN URLs (e.g. `bootstrap@5.3.8`); add `integrity="sha384-..."` SRI hashes on all CDN `<link>` and `<script>` tags — browser refuses to load if hash does not match |
| T-01-02 | Tampering | `data-turbo-permanent` sidebar DOM | accept | Low risk: sidebar DOM is server-rendered; only class toggles happen client-side; no sensitive data in sidebar DOM |
| T-01-SC | Tampering | CDN package supply chain | mitigate | SRI integrity attribute blocks tampered CDN payloads; packages are well-established (Bootstrap 14yr, Turbo 4yr+); no npm install required (CDN link only) |
</threat_model>
