    - Namespace: `Backlot.Studio.Services`
    - Class: `public class BasicAuthHandler : DelegatingHandler`
    - Constructor: accepts `IHttpContextAccessor httpContextAccessor` (stored as `_httpContextAccessor`)

      3. If not null/empty, set `request.Headers.Authorization = new AuthenticationHeaderValue("Basic", basicAuthHeader)`
      4. Call `base.SendAsync`, receive response
      5. If `response.StatusCode == HttpStatusCode.Unauthorized` — throw `BacklotApiUnauthorizedException`
      6. Return the response
    - Required using statements: `System.Net.Http.Headers`, `Microsoft.AspNetCore.Http`

    - Private helper: `private async Task<T?> GetAsync<T>(string path, CancellationToken ct = default)` — calls `_httpClient.GetAsync(path, ct)`, calls `response.EnsureSuccessStatusCode()`, then `ReadFromJsonAsync<ApiEnvelope<T>>()`, returns `envelope?.Body`

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ASP.NET Core Session → BasicAuthHandler | Session credentials read inside SendAsync; session is server-side only but must not be accessible to client JS |
| BasicAuthHandler → Backlot API | Authorization header carries reversible base64 credentials; must be HTTPS-only |
| Backlot API 401 → AuthenticatedPageModel | 401 exception must produce a full-page redirect, not a Turbo Frame-scoped redirect |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Information Disclosure | `BasicAuthHeader` in `ISession` | mitigate | Session cookie is `HttpOnly = true` (inaccessible to JS), `SameSite = Strict`, `SecurePolicy = Always` (HTTPS-only); `IsEssential = true` bypasses consent gates |
| T-02-02 | Information Disclosure | Basic Auth over HTTP | mitigate | `CookieSecurePolicy.Always` on session cookie + `UseHttpsRedirection()` in middleware pipeline ensures credentials only transit over TLS |
| T-02-03 | Elevation of Privilege | `SignInAsync` before credential validation | mitigate | `BacklotApiClient.IsAuthenticatedAsync()` is called BEFORE `SignInAsync` in Login.cshtml.cs (Plan 01-03); handler removes session key on failure |
| T-02-04 | Spoofing | 401 redirect captured inside Turbo Frame | mitigate | `Response.Headers["Turbo-Visit-Control"] = "reload"` in `SafeApiCall` forces full-page navigation regardless of frame context |
| T-02-05 | Information Disclosure | `ISession` injected directly into `DelegatingHandler` | mitigate | `BasicAuthHandler` constructor accepts `IHttpContextAccessor` (singleton-safe); reads `HttpContext?.Session` inside `SendAsync` only — documented as mandatory to prevent `ObjectDisposedException` |
| T-02-06 | Elevation of Privilege | Session fixation | mitigate | `HttpContext.SignInAsync` issues a new auth cookie on successful login (Plan 01-03); `Session.Clear()` on logout destroys session data |
| T-02-SC | Tampering | NuGet supply chain | accept | No external NuGet packages are installed in this plan; all services use in-box ASP.NET Core shared framework |
</threat_model>
