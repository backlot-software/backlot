<objective>
Remove the "Edit Roles" feature from Backlot.Studio and replace it with a "Download HTTP request" action. The action downloads a raw `.http` request file (VS Code REST Client / Rider format) for `POST /api/role/{RoleType}/persist`, pre-filled with the role's current field values and a credential placeholder (never real credentials).

Purpose: Give developers a ready-to-edit request template for re-persisting a role via their own tooling, while removing the in-app editing surface entirely.
Output: Edit page deleted; a `.http`-download handler + action added to the role detail page; dead `Saved`-banner code removed; solution builds.
</objective>

Delete both edit-page files: `Backlot.Studio/Pages/Roles/Edit.cshtml` and `Backlot.Studio/Pages/Roles/Edit.cshtml.cs` (use `git rm` or the filesystem). These are the only carriers of `EditModel`, the `/roles/{roletype}/{uid}/edit` route, and the `?saved=1` redirect — grep confirmed no other references.

In `Detail.cshtml.cs`:

1. Remove the now-dead `Saved` property and its preceding comment block (the `[BindProperty(SupportsGet = true)] public bool Saved { get; set; }` plus the comment about the query flag). It was only ever set by the deleted edit redirect.

2. Add a new handler `OnGetDownloadAsync` (reachable via `?handler=Download` on the existing `/roles/{roletype}/{uid}` route). It must NOT rely on the GET-populated `RoleData` (handler invocations do not share it), so it re-fetches the role itself. Model it exactly on the existing `OnGetAsync` fetch pattern:
   - Call `SetUserContext()`.
   - If `Uid` is blank then return `NotFound()`.
   - Re-fetch via `SafeApiCall(async () => await _api.PlayAsync<JsonElement>("seekbase", "detail", new { For = Uid }))`; if the redirect is non-null return it; then `var rd = env?.Body.Unwrap("Role");` (same shape as OnGetAsync). If `rd is null` or `rd.Value.ValueKind != JsonValueKind.Object` then return `NotFound()`.
   - Wrap the fetch in the same `catch (Exception ex) when (ex is HttpRequestException or TaskCanceledException)` used by OnGetAsync; log a warning and return `NotFound()` on failure. Never throw out of the handler.
   - Build the file text via a private helper `BuildHttpRequest(JsonElement roleData)` and return `File(System.Text.Encoding.UTF8.GetBytes(content), "text/plain", fileName)` — this `File(byte[], contentType, fileDownloadName)` overload sets `Content-Disposition: attachment` so the browser saves the file.

3. Add private helper `BuildHttpRequest(JsonElement roleData)` producing the `.http` text with these lines in order:
   - `@baseUrl = {baseUrl}` where `baseUrl = _api.BaseUrl.ToString().TrimEnd('/')`. `IBacklotApiClient.BaseUrl` already reflects the configured `BacklotApi:BaseUrl` value (default `https://localhost:7221`) set in `Program.cs`; reuse it rather than injecting `IConfiguration` — no new constructor dependency. Trim the trailing slash the `Uri` adds.
   - A blank line.
   - `POST {{baseUrl}}/api/role/{RoleType}/persist` (use the bound `RoleType`, default `Persist`).
   - `Content-Type: application/json`
   - A comment line (prefix `#`) directly above the Authorization line telling the user to supply their own base64 `username:password`, noting Studio never embeds credentials.
   - `Authorization: Basic <base64 of username:password>` — a PLACEHOLDER string only. Do NOT read or embed any session credential: the project's security boundary is that credentials never reach the browser (see ./.claude/CLAUDE.md "What NOT to Use"). This is the T-lg9-01 mitigation.
   - A blank line.
   - The JSON body from `BuildBody(roleData)`.

4. Add private helper `BuildBody(JsonElement roleData)`: iterate `GetNonSystemFields(roleData)` (already ordered Uid-first) and populate a `System.Text.Json.Nodes.JsonObject` (preserves insertion order), assigning each `(Key, Value)` string pair as `obj[Key] = Value`. Return `obj.ToJsonString(new JsonSerializerOptions { WriteIndented = true })`. Values serialize as JSON strings — acceptable for a hand-editable template per scope; keep it robust and never throw. Emitting raw underlying JSON value kinds is optional and NOT required.

5. Add private helper `BuildFileName()` returning `{RoleType}-{Uid}.http` with every char in `Path.GetInvalidFileNameChars()` replaced by `_` (e.g. `Persist-{uid}.http`).

Match existing file style: `System.Text.Json` (add `using System.Text.Json.Nodes;` if needed), nullable-enabled, the `AuthenticatedPageModel` base, `SetUserContext()`, and the `SafeApiCall` tuple pattern. Do NOT touch OnGetAsync's empty-uid redirect to `/Roles/Persist` (out of scope).
